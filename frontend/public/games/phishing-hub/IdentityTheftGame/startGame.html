Game for identity theft awareness

Aim - Player has to pass through correct door.

Rules - Level 1

There are true/false questions.

For each question, there are two doors GREEN (representing TRUE) and RED (representing FALSE).

Player has to choose right door to pass else they clash and game ends!

Rules - Level 2

There are multiple choice questions.

For each question, three answer options are provided (A, B and C) out of which one is correct. Each answer option is represented by a door of specific color (A=GREEN, B=RED , C=ORANGE).

Player has to choose right door (i.e. correct answer) to pass else they clash and game ends!
